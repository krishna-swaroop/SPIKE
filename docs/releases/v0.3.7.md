# SPIKE 0.3.7 - Windows community preview

This candidate provides a Windows x64 installer and SHA-256 checksum. Linux and
Apple Silicon macOS remain on [v0.3.5](https://github.com/wayri/SPIKE/releases/tag/v0.3.5).
Intel macOS remains held.

## Verification

The [clean Windows build](https://github.com/wayri/SPIKE/actions/runs/37217446360)
passed frozen-worker, installed CLI/runtime, reinstall, desktop startup and
uninstall checks; Rust checks passed 38 tests with one ignored.
[Source checks](https://github.com/wayri/SPIKE/actions/runs/37217447958), the
production frontend build and focused UI regressions passed. Historical local
fixture/cache failures were resolved and all 70 tests in their affected modules
passed. Required human review was confirmed before preview publication.

The installer SHA-256 is
`26905e80b9e428c703c41b8b7b5a5b3a2ee0f95d9ab4128a8d7993711002681e`.
Detailed native interaction acceptance is separate from desktop startup checks.

## Changes

- EM chamber content fills its reserved viewport row. EM controls use a compact
  toolbar and minimize to the bottom tool shelf, with a separate restore action.
- Saved angular radiation patterns without an explicit origin are anchored to
  the board antenna. Explicit physical origins retain their original coordinates.
- PI starts with unassigned nets and no default source or sink. Unassigned
  terminals do not float at the coordinate origin; terminal context menus support
  deletion, with project history retained.
- The Python workspace adds a movable, resizable editor, visible run state,
  stop controls, readable syntax and dedicated output actions.
- Completed scripts can show admitted physical geometry, fields and plots in the
  main viewport. Closing the script view restores the board view.
- Optional external EMerge examples have a pinned source manifest and retained
  upstream license. EMerge remains a separately installed runtime.

## Setup and limitations

See [Windows installation](../WINDOWS_INSTALLER.md),
[Python and EMerge integration](../SPIKE_EM_UI_BACKPORT.md),
[PI setup](../PI_PATH_ANALYSIS.md) and [solver status](../SOLVER_STATUS.md).
The ESP32 saved radiation example is an approximate surrogate; pattern radius
is a visual amplitude scale, not an observation distance. These presentation
changes do not establish antenna convergence or full-wave accuracy for a PCB.
