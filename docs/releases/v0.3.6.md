# SPIKE 0.3.6 - Windows community preview

This release provides an unsigned **Windows x64 installer** and its SHA-256
checksum. Linux and Apple Silicon macOS packages remain available in
[v0.3.5](https://github.com/wayri/SPIKE/releases/tag/v0.3.5). Intel macOS remains
held pending completion of platform checks.

## Changes

- Layer controls follow the focused board. Each occurrence, including local
  duplicates, retains its own visibility, opacity and quick layer preference
  through `.spike` save/open.
- Multiboard 2D highlighting uses SPIKE teal and the exported board outline to
  align source artwork with net geometry. Hidden source layers no longer cause
  an additional fallback board image.
- The separate assembly workspace contains the production board viewport,
  separated 2D layout, physical 3D placement, fitting, navigation and assembly
  handling controls. Startup reads are sequenced before connector discovery.
- Entering EM or reviewing results no longer opens the chamber automatically.
  Chamber display is an optional saved presentation setting.
- The Python editor adds incremental syntax rendering and guarded editing
  actions. Explicit external interpreters can use the installed SPIKE SDK and
  bundled extension resources.
- Resource staging preserves the source configuration and excludes local
  caches. The default local installer path stages resources after worker build.

## Verification and limits

The release uses the Windows packaging workflow, which checks the frozen worker,
CLI commands, silent installation, reinstall, installed desktop startup and
uninstall before emitting the installer. Source checks and focused UI,
persistence and resource regressions are required before publication.

These changes do not qualify solver accuracy or promote experimental assembly
models to full-wave analysis. Missing source component models can still appear
as footprint placeholders. See [solver status](../SOLVER_STATUS.md),
[multiboard workflows](../MULTIBOARD_HARNESS_ASSEMBLIES.md) and
[Windows installation](../WINDOWS_INSTALLER.md).

## Early release and development disclosure

SPIKE's development effort is largely LLM-driven under human review. This is
still a very early community release and may contain instabilities, bugs and
incomplete behavior. The community is invited to test and provide reproducible
[feedback](https://github.com/wayri/SPIKE/issues).

inputs, assumptions and results before engineering reliance. The installer is
