# SPIKE 0.3.8 - Windows community preview

Windows x64 installer and SHA-256 checksum. Linux and Apple Silicon macOS remain
on [v0.3.5](https://github.com/wayri/SPIKE/releases/tag/v0.3.5); Intel macOS is held.

## Changes

- Independent copper, solder-mask, silkscreen and board-body visibility and
  opacity in single-board and assembly views. Imported layers stay active;
  partial exports keep complete retained copper. Shared materials and combined
  copper meshes are separated by layer before batching.
- Resolved 3D components replace their stand-ins permanently. Copper controls
  do not hide component models or change their opacity.
- Canonical net selection and highlighting stay scoped to each board occurrence,
  including imported numeric net identifiers and retained connector pin maps.
- Movement controls include rotation rings alongside translation arrows.
- Embedded PI, SI, Thermal and EMI study results appear directly in Results with
  one-click validated display. A file chooser is offered only when a result is
  absent. Stale or rejected results show a recovery message.
- Thermal/SI study switching clears stale drafts. Automatic connector and field
  reads are serialized, and repeated startup effects share one pending read.
- Multi-board planning distinguishes validated plans from completed analyses.
  Arduino and Raspberry Pi carrier/HAT walkthroughs document supplied reduced
  PI/SI/Thermal models, results, provenance and limitations.

## Verification and limitations

Publication requires source checks and the clean Windows packaging workflow,
including frozen-worker, installed CLI/runtime, reinstall, desktop startup and
uninstall checks. Focused regressions cover imported layer boundaries,
occurrence identity, retained results, asynchronous admission and study switching.

No numerical solver implementation is changed from the human-reviewed 0.3.7
release. Reduced coupled-study values do not establish distributed SI,
full-wave EM, spatial board temperature or engineering qualification.
Native interaction acceptance is distinct from installer/startup checks.
Generated third-party CAD packages remain local and are not release assets.
