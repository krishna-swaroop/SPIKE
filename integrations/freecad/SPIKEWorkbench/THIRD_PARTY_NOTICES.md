# Third-party and asset review

This source workbench is MIT licensed; see `LICENSE`. FreeCAD, KiCad, the SPIKE worker, external solver engines, and their runtimes are separate installations and are not included here. Their licenses and dependency notices must be assessed for any combined distribution.

The three local FreeCAD screenshots in `docs/images` contain application UI and the SPIKE demo PCB. Their capture source and limitations are recorded in `docs/ASSET_PROVENANCE.md`. Redistribution rights for the FreeCAD UI, demo board, and any visible package models must be confirmed before a public standalone release. The offscreen Qt panel renders, result charts, toolbar icons, and `workflow.svg` were authored for workbench documentation; their provenance is recorded in the same file.

This file is a scoped release review record, not a blanket grant of rights. Check icons, fonts, models, examples, screenshots, and any newly copied assets before packaging a public release.
