The lockfile records transitive packages and their metadata. Retain the actual
license/copyright notices supplied by every dependency distributed with your

not required by this package. A host may supply assets generated by separately
installed KiCad or other tools; those models/boards retain their own provenance
and terms. The demo geometry and virtual data were authored for this project.

Original extracted and new SPIKE-owned source follows the included Apache-2.0
license unless an individual file records otherwise. See docs/EXTRACTION.md
for the extraction boundary.

The optional MCAD adapter uses the public API of the separately installed
`occt-import-js` dependency. Its JS/WASM runtime is copied unchanged from the
locked npm package into `public/vendor/occt-import-js` for local worker loading.
The core library does not bundle it. See `licenses/OCCT_IMPORT_JS-LGPL-2.1.txt`,
`licenses/OCCT-LGPL-2.1.txt`, the runtime's notices and `docs/MCAD_IMPORT.md` for
source/rebuild references, actual license texts and model fixture provenance.

Apache-2.0 SPIKE material. No external CAD viewer implementation was copied.
